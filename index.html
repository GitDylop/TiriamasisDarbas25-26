Reikšmių perrikiavimas

Duota komanda: 
    def reiksmiu_perrikiavimas(reiksmes):
        pass

Sąlyga:

  • reiksmes – sąrašas su trimis skaičiais, pvz.: [3, 7, 1]
  • Priskirk kiekvieną elementą kintamiesiems a, b, c
  • Grąžink kintamuosius atvirkštine tvarka kaip sąrašą
  • Nenaudok reverse() ar [::-1]

Pavyzdžiai:

[3, 7, 1] → [1, 7, 3]
[10, 20, 30] → [30, 20, 10]
def reiksmiu_perrikiavimas(reiksmes): pass
